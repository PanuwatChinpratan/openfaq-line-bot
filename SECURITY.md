# Security

Please report vulnerabilities privately to the repository owner instead of opening a public issue.

- Do not commit `.env`, model caches, LINE tokens or real customer conversations.
- Rotate any secret that has appeared in screenshots, logs or chat.
- Production deployments must use HTTPS, a strong `ADMIN_PASSWORD_HASH` and restricted origins.
- OpenFAQ is a FAQ system, not a place to process passwords, OTP, card or account data.
